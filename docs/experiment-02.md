# Second full-song experiment: 10CM - 너에게 닿기를

실행일: 2026-10-05. 첫 실험 Wake의 채보 품질이 거의 실패라는 사용자 평가에 따라
다른 입력으로 같은 파이프라인을 다시 실행했습니다. 모델/감도를 바꾸지 않은 자동 초안입니다.

## 입력과 실행

- [10CM - 너에게 닿기를 [가사/Lyrics]](https://youtu.be/qRdFd34gnOY).
- yt-dlp `bestaudio/best`: format 251, Opus 48 kHz 스테레오, 약 134.321 kbps,
  2,664,613 bytes. ffprobe 길이는 158.701초입니다.
- 로컬 웹 앱의 업로드 API로 새 작업을 등록했습니다. 작업 ID:
  `b89900de0bb84795a5d6180c6375e519`.
- Demucs htdemucs → ADTOF Frame_RNN → MusicXML → MuseScore 4.7.5를
  전체 파일에 실제 실행했습니다. 두 모델의 실행 장치는 PyTorch MPS였습니다.
- 이전과 동일하게 감도 1.0, BPM/quarter-note phase 자동, 4/4, 16분 격자입니다.
  박자와 downbeat를 자동 판별한 결과는 아닙니다. 타격 수동 수정은 하지 않았습니다.
- 최초 실행에서 약 57초에 PDF/SVG까지 완료했습니다. 모델 추론 재시도는 없었습니다.

## 결과

| 항목 | 값 |
| --- | --- |
| 추정 BPM | 125.964 |
| Quarter-note phase | 0.0368초 |

| PDF / SVG | A4 2페이지 / 2페이지 |
| 원시 / 격자 타격 | 776 / 774 |
| 같은 악기/격자 위치 중복 병합 | 2 |
| 킥 / 스네어 / 탐 / 하이햇 / 심벌 | 206 / 228 / 36 / 279 / 27 |
| 평균 타격-격자 시간차 | 40.8 ms |
| 비트 회귀 잔차 | 36.6 ms |

첫 결과의 하이햇/심벌 검출은 88/344회, 이번 결과는 279/27회였습니다.
다른 곡이고 길이도 다르므로 이 분포만으로 정확도 향상을 결론내릴 수 없습니다.
평균 시간차 또한 채보 정확도나 F1 점수가 아닙니다.

## 출력 검증과 남은 평가

- PDF 두 페이지를 모두 Poppler로 이미지화하고 육안 확인했습니다. 제목의 한글,
  타악기 글리프와 보표가 정상 표시되며 잘림이나 겹침을 관찰하지 못했습니다.
- MusicXML은 84마디, 타악기 음표 774개이며 두 성부의 모든 마디 길이가
  각각 48 divisions인 것을 확인했습니다. PDF/SVG 페이지 수도 일치합니다.
- MuseScore는 출력 후 종료 오류(-6)를 냈습니다. 새 출력의 SVG XML과 PDF 구조가
  유효함을 검증한 뒤 사용했고, 원본 `engraver.log`를 보존했습니다.
- 검출의 정답 여부 및 첫 마디 위치는 기준 악보/원음과 아직 대조하지 않았습니다.
  특히 스네어·탐 분류, 심벌/하이햇 누락과 오검출, 마디의 downbeat를 확인해야 합니다.
- 자동 4/4·16분 격자는 원음의 세부 리듬을 근사한 초안입니다. 수동 보정한
  악보로 오해하지 않도록 원시 이벤트와 격자 MIDI를 함께 제공합니다.

결과 묶음: PDF, SVG 2개, MusicXML, 원시/격자 MIDI, 이벤트/분석 JSON,
원본 출처와 SHA-256, 렌더러 로그, 분리된 드럼 FLAC 및 이 기록.
이전 Wake 결과와 별도 경로에 저장했습니다.

재현용 다운로드:

```sh
uvx --from yt-dlp yt-dlp --no-playlist -f 'bestaudio/best' \
  --write-info-json -o 'work/experiment-02/source.%(ext)s' \
  'https://youtu.be/qRdFd34gnOY'
```

웹 앱에서 이 파일을 기본 설정으로 업로드하면 됩니다. 장치 및 수치 연산에 따라
타격 검출이 조금 달라질 수 있습니다. 의존성은 `uv.lock`으로 고정합니다.
