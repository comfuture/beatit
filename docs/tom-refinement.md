# 탐 높이 후처리

`Options.tom_refinement`는 기본값이 `false`인 선택적 후처리입니다. 검출 완료 후
`make_score`가 호출하며 저장된 `stem-toms.flac`과 `stem-kick.flac`을 사용합니다.
기존 ADTOF 모델과 타격 시점은 그대로 유지합니다. 별도 모델 다운로드나 추가 의존성은 없습니다.

## 판정

- 원래 탐(47)의 타격 뒤 25–115, 50–150, 80–200 ms 구간에서 65–650 Hz 공명 분포를 측정합니다.
  다음 탐이 가까우면 창을 줄이며, 충분한 길이의 창이 두 개 이상 있어야 합니다.
- 창 사이 공명 위치가 2.5 반음 이내로 안정적이고 에너지가 집중된 후보를 사용합니다.
  킥 스템과 공명·분포가 비슷하고 킥이 겹치거나 킥 에너지가 지배적이면 보정을 보류합니다.
- 다른 악기와 35 ms 이내에 겹치지 않는 후보로 곡 전체의 상대적인 두 음색 그룹을 만듭니다.
  그룹별 최소 4개, 공명 위치 차이 최소 5반음과 분포 차이가 있어야 합니다.
- 후보와 그룹의 유사도가 0.90 이상, 두 그룹 점수 차이가 0.08 이상이며 창별 판정도 같을 때만
  저음 탐(45) 또는 고음 탐(50)으로 바꿉니다. 나머지는 기존 탐(47)으로 유지합니다.

숫자는 보정된 확률이 아닌 휴리스틱 기준입니다. 공명 피크는 기본 주파수나 실제 탐 크기를 뜻하지 않습니다.
두 그룹이 같은 킥 누출이나 다른 음원 차이에서 생길 수도 있으므로 원음과 대조해야 합니다.
한 종류의 탐만 있거나 녹음으로 음색 차이가 사라진 곡에서는 구분을 강제하지 않습니다.
누락된 타격을 복원하거나 동시에 친 여러 탐을 분리하지 않습니다.

## 출력과 취소

자동 보정 이벤트에는 `tom_source_pitch: 47`과 `tom_match_score`를 기록합니다. 옵션을 끄면
이 태그가 있는 이벤트만 원래 탐으로 되돌립니다. 태그 없이 수동 입력한 45/50 이벤트는 유지합니다.
원시 검출 이벤트 파일과 이전 렌더링 세대도 보존됩니다. MusicXML에서는 서로 다른 보표 위치를,
MIDI에서는 GM 45/50을 사용합니다. 미분류 탐 47도 별도 위치로 표시합니다.

`tom-refinement.json`에는 후보별 타격 시각, 판정 또는 보류 사유, 공명 위치, 그룹별 기준과 수가
포함됩니다. 새 렌더링의 ZIP에 포함되며 `/api/jobs/{id}/files/tom-refinement.json`으로도 받습니다.
이전 작업에 탐·킥 스템이 없다면 원래 표기를 유지하고 새 분석이 필요하다는 경고를 표시합니다.

## Wake 검증 (2026-10-06)

동일한 기존 DrumSep/ADTOF 분석 캐시에 적용한 결과는 탐 후보 197개 중 저음 80개,
고음 37개, 미분류 80개입니다. 이것은 자동으로 변경된 수이며 정답률 측정이 아닙니다.
타격 시각·세기·velocity·다른 악기 이벤트는 변경하지 않았고 자동 보정 취소 시 원시 이벤트와
동일해지는 것을 확인했습니다. 합성 감쇠 공명, 단일 음색, 킥 누출, 짧은 꼬리,
수동 편집 보존 및 모델 추론 없는 캐시 재생성을 회귀 테스트합니다.
