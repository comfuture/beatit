# Third experiment: 10CM - 너에게 닿기를, DrumSep + Beat This!

실행일: 2026-10-06. [두 번째 실험](experiment-02.md)과 같은 원본 파일에 개선된
파이프라인을 실행한 자동 초안입니다. 기준 악보와 대조한 정확도 측정은 아닙니다.

## 입력과 실행

- [10CM - 너에게 닿기를 [가사/Lyrics]](https://youtu.be/qRdFd34gnOY), yt-dlp format 251
  (Opus 48 kHz 스테레오, 134.321 kbps), 2,664,613 bytes.
- SHA-256 `0fcf9ae313af60bf1377318ed5907faf44ebb270f540a430e5c4ea2ae53d1cf9`.
  두 번째 실험의 원본과 같은 파일입니다.
- 설정은 이전과 같습니다: BPM/첫 마디 자동, 4/4, 16분 격자, 감도 1.0, 전체 믹스,
  MuseScore 4.7.5, Apple M5 PyTorch MPS. 타격을 수동 수정하지 않았습니다.
- 파이프라인: Demucs htdemucs → DrumSep MDX23C 5스템 → ADTOF(전체 드럼 + 각 스템,
  클래스별 평균) → Beat This! `final0` 비트·다운비트 → MusicXML → MuseScore.

| 처리 시간 | 56.8초 | 122.6초 |

- 이전 결과는 대부분의 타격이 16분 격자에서 칸 폭(약 119 ms)의 4분의 1 넘게 벗어나
  있었습니다. Librosa 비트가 실제 타격보다 약 35 ms 늦었기 때문이며, 작은 타이밍 차이로도
  옆 칸에 붙을 수 있는 상태였습니다. 새 격자에서는 거의 모든 타격이 격자 위에 놓입니다.
- 같은 타격 692개를 비교하면 32개가 박 안의 16분음표 위치를 바꿨습니다. 모든 타격의
  마디 내 위치는 바뀌었습니다. 이전 악보의 마디 시작이 실제 다운비트보다 약 3박
  어긋나 있었기 때문입니다. 새 악보는 킥 1·3박, 스네어 2·4박에 놓입니다.
- 첫 다운비트 앞의 타격은 1마디의 못갖춘마디 쉼표 뒤에 놓입니다.
- 열린 하이햇은 O 기호로 표시합니다. 처음 규칙(감쇠 8 dB 미만)에서는 이 곡의 하이햇
  107/221개가 열림으로 나왔습니다. 작은 타격이 잡음 바닥 가까이에 있으면 서서히 감쇠한
  것처럼 보였기 때문입니다. 잡음 바닥 대비 감쇠 비율 조건을 추가해 64개로 줄였습니다.
  MDB에서 정밀도는 0.71→0.74, 재현율은 0.55→0.51입니다.
- 심벌은 34개 늘었습니다. 이 증가가 정확한 검출인지 오검출인지는 아직 확인하지 않았습니다.

## MDB Drums 검증 (23곡, 50 ms 허용)

| 단계 | 기존 | 개선 |
| --- | --- | --- |
| 비트 F (mir_eval) | 0.718 | 0.934 (믹스/드럼 중 잔차 낮은 쪽) |
| 16분 격자 칸 정확도 | 0.892 | 0.960 (위상 보정 포함) |
| 5종 타격 F, 고스트 노트 제외 | 0.864 | 0.882 (2-fold 교차 검증) |
| 다운비트 F | 미지원 | 0.860 (믹스) |

DrumSep 스템만 ADTOF에 넣으면 0.788로 오히려 낮았습니다. 전체 드럼과 스템 활성값을
평균했을 때만 개선되었습니다. 크래시/라이드 구분은 5스템 모델에서 근거가 없어
구현하지 않았습니다. 고스트 노트 표시는 검출된 스네어에서 F 0.32라 보류했습니다.
