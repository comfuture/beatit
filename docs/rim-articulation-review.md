# 림샷·크로스스틱 분리 검토 (2026-10-06)

현재 ADTOF 검출 클래스와 `Event`에는 스네어(38)만 있고 일반 스네어, 림샷,
크로스스틱을 구분하는 주법 정보는 없습니다. 탐 후처리와 같은 위치에 스네어 주법 후처리를
연결할 수 있지만, 이번 검토에서는 주법을 자동 변경하지 않았습니다.

사용자가 말한 림은 헤드와 림을 함께 치는 림샷입니다. QWER 「고민중독」 도입부는
사용자가 제시한 크로스스틱 참고 구간입니다. 개별 타격 시각에 정답 라벨을 붙인 자료는 없습니다.
[Roland의 주법 설명](https://static.roland.com/manuals/v71_reference_v210/en-US/367145995532552843.html)은
림샷과 손을 헤드에 둔 크로스스틱을 구분합니다. 전자 드럼의 센서/velocity 전환 규칙을
녹음 음원의 분류 규칙으로 그대로 적용해서는 안 됩니다.

## 실제 입력과 측정

- QWER 입력: <https://www.youtube.com/watch?v=hFTs6HbtxbE>, 메타데이터 제목
  `QWER - 고민중독 [가사/Lyrics]`, 첫 45초를 현재 Demucs/DrumSep/ADTOF 경로로 분석.
  스네어 후보 63개 중 3.4–12초 참고 창에 13개(첫 3.78초, 마지막 11.87초)가 검출됨.
- 같은 곡의 25–45초 스네어 후보 35개를 대조함. 후반을 림샷 정답으로 가정하지 않음.
- 10CM 「너에게 닿기를」: 기존 같은 브랜치 분석 캐시의 스네어 후보 231개를 대조함.
  사용자가 림샷이 많이 있다고 설명했지만 개별 후보의 주법은 확정하지 않음.
- 검출 시각 ±45 ms에서 스네어 어택을 찾고 첫 60 ms의 음량을 정규화한 스펙트럼을 측정함.
  0–40 ms와 80–180 ms의 에너지 비율로 꼬리 길이도 비교함.
  동일 타격의 음량을 1/4로 줄였다가 정규화했을 때 특징은 같았음.
  스네어 스템·분리 드럼·전체 믹스에서 각각 대조함.

저역 제외 특징의 중앙값:

| 구간 | 후보 수 | 스네어 평탄도 (0.5–10 kHz) | 고역/중역 비율 (3–10 / 0.5–2 kHz) |
| --- | ---: | ---: | ---: |
| QWER 도입 참고 | 13 | 0.455 | 6.32 dB |
| QWER 후반, 주법 미확인 | 35 | 0.433 | 2.97 dB |
| 10CM, 주법 미확인 | 231 | 0.343 | 6.04 dB |

저역을 포함한 평탄도(0.2–10 kHz)는 QWER 도입 0.098, 후반 0.273으로 달랐지만,
저역을 제외하면 분포가 겹칩니다. 고역/중역 비율 역시 도입 참고와 10CM 후보가 겹칩니다.
어택 대비 꼬리 에너지의 중앙값은 각각 -16.41, -18.57, -15.25 dB여서
단순히 짧은 꼬리를 크로스스틱이라고 정하는 규칙도 뒷받침되지 않습니다.

분리 드럼의 저역 제외 평탄도도 QWER 도입 0.462, 후반 0.456으로 비슷합니다.
음량 정규화는 EQ·압축·게이트·동시 타격·분리 누출을 제거하지 않습니다.
정규화된 음색 특징과 원음 음량의 상관도 남아 있어, 녹음 처리의 영향을 점검해야 합니다.

## 판단과 다음 구현 범위

**QWER 도입 참고 구간을 후보로 찾아 검토하는 후처리는 가능하지만, 두 녹음으로
림샷·크로스스틱의 자동 분리 정확도가 입증되지는 않았습니다.** 크로스스틱 참고와 다른 소리를
모두 림샷으로 간주할 수 없으며 일반 헤드샷과 강한 림샷은 특히 별도 검증이 필요합니다.

후속 구현은 다음 조건을 갖추는 것이 적절합니다.

1. 기존 스네어 타격 뒤에서 `head / rimshot / cross_stick / unresolved` 주법을 판정하는
   선택적 후처리로 연결하고 타격 시점은 유지. 기존 검출기에 잡히지 않은 타격의 복원은 별도 문제.
2. 곡 안에서 확인한 주법별 예시로 기준을 만들고, 어택·저역 몸통·고역 잡음·꼬리를 함께 비교.
   창과 스템을 바꾸어도 판단이 유지될 때만 보정하고, 동시 악기/누출/약한 대비는 미확정 유지.
3. 같은 곡의 다른 구간과 다른 녹음에서 주법별 정밀도·재현율과 혼동행렬을 측정.
   림샷 정답 예시가 없는 이번 자료에서 정확도 수치를 만들지 않음.
4. 크로스스틱은 GM Side Stick(37), 림샷은 스네어(38)에 별도 주법 표기를 보존.
   [GM 기본 타악기 표](https://www.cs.cmu.edu/~music/cmp/archives/cmsip/readings/GMSpecs_PercMap.htm)의
   Side Stick을 림샷과 공통으로 사용하지 않음. 일반 GM 표에는 독립적인 림샷 항목이 없음.

검토 자료는 로컬 `work/rim-review/`에 저장했습니다. `features.json`은 타격별 특징,
`checks-summary.json`은 저역 제외/원음 대조, `provenance.json`은 입력 해시와 분석 범위입니다.
브라우저 검토 페이지의 점을 누르면 해당 타격 직전으로 이동하며 원음/스네어 스템을 전환할 수 있습니다.
입력 파일과 새 ML 분석 결과를 사용했고 모델 결과를 합성하거나 주법 정답으로 대체하지 않았습니다.
